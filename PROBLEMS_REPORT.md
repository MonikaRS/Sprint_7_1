## 🔍 АНАЛИЗ ПРИЧИН ПРОБЛЕМ

### Проблема 1: 405 ошибки
**Коренная причина:** Неправильные URL endpoints  
НЕПРАВИЛЬНО (было): /courier
ПРАВИЛЬНО (должно быть): /api/v1/courier

text
**Анализ:** API сервер ожидал полный путь с префиксом `/api/v1`, но в тестах использовались сокращённые URL

### Проблема 2: 400 при отмене заказа
**Коренная причина:** Неправильный формат JSON в теле запроса  
НЕПРАВИЛЬНО: {"track": 123456} (числовой тип)
ПРАВИЛЬНО: {"track": "123456"} (строковый тип)

text
**Анализ:** API ожидал строковое значение для поля `track`, но тесты отправляли числовое значение

### Проблема 3: Ошибки компиляции
**Коренная причина:** Человеческий фактор при копировании/вставке кода  
- Дублирование аннотаций `@After`
- Неправильное количество закрывающих скобок
- Нарушение структуры классов
