## 🎯 Цель проекта
Автотесты для проверки функциональности API сервиса доставки:
- Создание, авторизация и удаление курьеров
- Создание, получение и отмена заказов
- Валидация входных данных и обработка ошибок

## 🛠 Технологии
- **Java 11+**
- **Maven** - управление зависимостями и сборка
- **JUnit 4** - фреймворк для тестирования
- **REST Assured** - тестирование REST API
- **Allure** - генерация отчётов о тестировании

## 🚀 Команды для работы

### Сборка и тестирование
```bash
# Собрать проект
mvn clean compile

# Запустить все тесты
mvn test

# Запустить конкретный тестовый класс
mvn test -Dtest=CourierTest

# Создать JAR файл
mvn clean package

# Установить в локальный репозиторий Maven
mvn clean install
Генерация отчётов
bash
# Запустить тесты с генерацией Allure отчёта
mvn clean test

# Сгенерировать отчёт Allure
mvn allure:report

# Открыть отчёт Allure в браузере
mvn allure:serve
